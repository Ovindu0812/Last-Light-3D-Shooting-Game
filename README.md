# Last-Light-3D-Shooting-Game# Operation: Last Light
### Interactive 3D Shooting Game

## 1. Project Overview
Operation: Last Light is a single-player 3D shooting game developed as part of the SE3032 – Graphics and Visualization assignment.

The game takes place in a secret military research facility located deep within a forest. The player must explore the environment, overcome enemy soldiers, interact with objects, and reach the final research laboratory.

## 2. Project Objectives
- Develop an interactive 3D game environment.
- Implement player movement and shooting mechanics.
- Create custom 3D models using Blender.
- Implement realistic environmental physics interactions.
- Develop AI-controlled enemy movement and animations.
- Apply lighting, materials, and textures to enhance visual quality.
- Optimize the game for stable performance.

## 3. Technologies
- **Game Engine:** Unity
- **Programming Language:** C#
- **3D Modeling:** Blender
- **Version Control:** Git and GitHub
- **Development Environment:** Visual Studio Code

## 4. Game Environment

### Zone 1: Forest Entrance
The player begins in a forest environment containing trees, rocks, terrain, and a pathway leading to the military base.

### Zone 2: Military Base
A secured military area containing guard towers, barricades, enemy patrols, and interactive gates.

### Zone 3: Research Bunker
An underground research facility containing laboratories, security doors, and the final mission objective.

## 5. Planned Game Features
- First-person player movement
- Shooting mechanics
- Enemy navigation and animations
- Interactive doors
- Movable crates and barricades
- Custom 3D models
- Environmental lighting and texturing
- Mission completion system
